Validações executadas neste ambiente:

1. Estrutura da planilha enviada inspecionada: 52 colunas, com os 13 itens PCS identificados após os campos PROMIS-29.
2. Planilha fictícia criada preservando os 52 cabeçalhos e deixando os demais instrumentos em branco.
3. Cálculo PCS testado com o paciente fictício:
   - Ruminação: 11/16
   - Magnificação: 5/12
   - Desamparo: 13/24
   - Total: 29/52
   - Interpretação: Catastrofização moderada
4. Conversão do link Google Sheets testada com o formato informado:
   /spreadsheets/d/{ID}/export?format=xlsx&gid={GID}
5. O projeto foi alterado para gerar somente uma versão portátil .exe do Windows (electron-builder target portable).
6. Foi adicionada uma splash screen antes da janela principal, com barra de progresso e mensagens de carregamento.
7. package.json validado como JSON.
8. Os 8 arquivos TS/TSX de código passaram por verificação sintática usando TypeScript 5.8.3.

Limitação do ambiente de geração:
- A instalação dos pacotes npm externos não pôde ser concluída aqui por indisponibilidade/timeout de acesso ao registro npm.
- Por isso, o .exe portátil não foi empacotado neste ambiente.
- No Windows com Node.js e acesso à internet, execute GERAR_EXECUTAVEL_WINDOWS.bat ou npm run dist:win para gerar o arquivo na pasta release.
